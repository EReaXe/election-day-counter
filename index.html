Resmî API yanıtı bağımsız doğrulama veya canlı güncellik anlamına gelmez. Seçildiği parti bilinmiyorsa boş bırakılır.

Resmî API politikası ve bağlantı durumu

Siyasi kayıtlar ve seçim tarihleri için yalnızca izin verilen resmî API’ler kullanılır. Resmî HTML sayfası, haber, PDF, arama dizini veya üçüncü taraf derleme yedek veri kaynağı olamaz.

Bağlı API: İzmir Büyükşehir Belediyesi meclis üyeleri servisi. Milletvekilleri, güncel sandalye dağılımı, Cumhurbaşkanı ve gelecek seçim tarihleri için uygun API bağlantısı henüz kurulamadı.

Bu sayfa son başarılı API yanıtının yerel kopyasını kullanır. Otomatik veya canlı veri akışı değildir. Kaynak ve çalışma durumu veri dosyasında tutulur. İlçe adları da resmî API yanıtından alınır. API bağlantısı olmayan harita şekilleri genel arayüz etiketleriyle gösterilir. Harita çizimi görsel varlıktır; siyasi bilgi kaynağı değildir. Kaynaklar ve lisanslar.
